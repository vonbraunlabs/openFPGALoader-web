# OpenFPGALoader-web

Versão webassembly do openFPGALoader.
Este é um fork do [openFPGALoader-web]([[github.com/phdussud/pico-dirtyJtag](https://github.com/trabucayre/openFPGALoader)](https://github.com/YoWASP/openFPGALoader-web)), tendo um apenas um patch para usar a tangprimer20k.

## 🛠️ Configuração Rápida

### Build do projeto



1. **Para builder o projeto, no diretório execute**
   ```bash
   ./build.sh
   ```
2. **Em seguida, faça o packaging para gerar o pacote do node**

    ```bash
    ./package.sh
    ```
